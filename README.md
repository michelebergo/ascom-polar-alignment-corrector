# ASCOM Polar Alignment Corrector — interface proposal

A draft proposal for a new ASCOM device interface, `IPolarAlignmentCorrectorV1`,
for motorised devices that correct a mount's polar alignment in azimuth and
altitude (Avalon UPAS, MLAstro RPA, OpenAstroTech AutoPA, Zenit Align Mini,
OAPA and similar).

The draft is here: [IPolarAlignmentCorrectorV1.md](IPolarAlignmentCorrectorV1.md)

## Status

Draft for discussion on the ASCOM-Talk Developer forum. Nothing is final:
names, members and semantics are open to change. It is not an ASCOM
Initiative document and has not been endorsed by the Initiative.

## Feedback

Discussion happens on ASCOM-Talk Developer. Comments, corrections and
suggestions from device makers and client developers are also welcome as
issues or pull requests here.
